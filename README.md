# Portfolio ♡

A static, multi-page portfolio ready for GitHub Pages.

## Pages
- `index.html` — Home / Miffy artwork
- `projects.html` — Engineering projects
- `visual-arts.html` — Visual Arts, six clickable Instagram thumbnails, four horizontal cards
- `about.html` — About Me
- `styles.css` — Shared styling
- `assets/` — Miffy image, Instagram thumbnails, and downloadable resume

All pages are separate HTML documents. No build tools, JavaScript, or Instagram embeds are required.

**Artwork note:** Miffy does not belong to me. Fair use is a legal doctrine that promotes freedom of expression by permitting the unlicensed use of copyright-protected works in certain circumstances.
