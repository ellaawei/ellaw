# Ella Wei — Portfolio Website ♡

A static, multi-page portfolio ready for GitHub Pages.

## Pages
- `index.html` — Home / Miffy artwork
- `projects.html` — Engineering projects
- `visual-arts.html` — Visual Arts, six clickable Instagram thumbnails, four horizontal cards
- `about.html` — About Me
- `styles.css` — Shared styling
- `assets/` — Miffy image, Instagram thumbnails, and downloadable résumé

## Publish on GitHub Pages
1. Create a public GitHub repository (e.g. `portfolio`).
2. Upload **all files and the `assets` folder**, preserving the structure.
3. Open **Settings → Pages → Build and deployment**. Choose **Deploy from a branch**, branch **main**, folder **/(root)**, and Save.
4. Your site will appear at `https://ellaawei.github.io/portfolio/` (if the repository is named `portfolio`).

All pages are separate HTML documents. No build tools, JavaScript, or Instagram embeds are required.

**Artwork note:** The supplied Miffy and Instagram thumbnails may be subject to third-party copyrights. Ensure you have appropriate permission before publishing publicly.
